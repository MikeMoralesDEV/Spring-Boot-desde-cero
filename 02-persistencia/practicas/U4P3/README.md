# U4P3 — Aplicación web con persistencia

Diseña un pequeño dominio propio —o utiliza el ejemplo propuesto— y desarrolla una aplicación web que conserve sus datos en MariaDB.

El trabajo consiste en crear el proyecto con Spring Initializr, definir el modelo, crear una base de datos local vacía, mapear la entidad y construir el recorrido web para listar los registros y añadir uno nuevo mediante un formulario. También se documenta la organización por capas y se comprueba el funcionamiento de la aplicación. Como ampliación opcional, se proponen consultas personalizadas accesibles desde la vista.

Consulta el [enunciado completo](ENUNCIADO.md).

**Duración orientativa:** 4–6 sesiones de 50 minutos.

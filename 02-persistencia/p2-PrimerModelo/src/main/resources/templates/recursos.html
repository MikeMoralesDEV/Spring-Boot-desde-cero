¿Qué representa cada parte?

  • Recurso es una clase Java que describe los datos de un recurso.
  • Cada objeto contiene sus propios valores, como nombre y categoría.
  • recursos es una lista de objetos que el controlador prepara en memoria.
  • Model es el contenedor MVC que permite a Thymeleaf recibir esa lista.

Todavía no hay una entidad JPA ni una tabla asociada: cerrar y volver a iniciar la aplicación no guarda ni recupera cambios.

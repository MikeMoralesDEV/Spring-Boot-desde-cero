# Fase 1: No persistencia y SSR

P1–P6 son aplicaciones Spring Boot independientes. Los ejemplos trabajan progresivamente con Spring MVC y Thymeleaf, y mantienen sus datos en memoria: no usan base de datos ni guardan información entre ejecuciones.

Cada carpeta `p1springboot`–`p6springboot` contiene su propio `pom.xml`, wrapper de Maven, fuentes, recursos y pruebas. Para ejecutar una práctica, entra en su carpeta y usa `.\mvnw.cmd spring-boot:run`; para probarla, usa `.\mvnw.cmd test`.

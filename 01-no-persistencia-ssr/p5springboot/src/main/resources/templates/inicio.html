Recursos estáticos habituales

CSS, imágenes y JavaScript

Spring Boot publica por convención archivos de static/. Se referencian con th:href="@{/css/p5.css}", th:src="@{/images/chikapu.jpg}" o th:src="@{/js/app.js}". Así las rutas también funcionan si la aplicación se despliega bajo un prefijo de contexto.

Spring Boot sirve los archivos, pero no los comprime ni cambia su formato automáticamente. La optimización se prepara antes de publicarlos.

Qué significa optimizar una imagen

  • Tamaño en píxeles: evita servir una imagen de miles de píxeles si solo se verá en una tarjeta pequeña. Usa una versión adecuada al espacio.
  • Compresión: reduce bytes para que la descarga sea más rápida. En JPEG se puede ajustar la calidad: reducir demasiado produce artefactos.
  • Formato: WebP y AVIF suelen ofrecer archivos más pequeños a calidad visual comparable; hay que comprobar compatibilidad y conservar una alternativa si el público o los navegadores lo requieren.
  • Adaptación: CSS hace que la imagen quepa en la pantalla, pero no reduce por sí mismo el tamaño del archivo descargado.
  • Carga: loading="lazy" aplaza imágenes fuera de pantalla. No se recomienda en la imagen principal que aparece al abrir la página.

Esta imagen pesa aproximadamente 4 KB: ya es pequeña y no hace falta procesarla. Para este ejercicio basta con observar sus propiedades; más adelante se puede comparar el peso original y el optimizado con herramientas de imagen.

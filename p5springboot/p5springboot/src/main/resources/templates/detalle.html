¿Cuándo usar cada procesador?

  • th:replace: el fragmento define el elemento final; útil para cabeceras y pies.
  • th:insert: conservar el elemento anfitrión como contenedor.
  • th:include (obsoleto en Thymeleaf 3): no es la opción recomendada.

Pasar parámetros a un fragmento ayuda a reutilizar estructura manteniendo títulos, estado de navegación y contenido específicos de cada vista.
